# Discord NGワード自動置換Bot⚡

不適切な単語（NGワード）が発言されたときに、元の発言を即座に削除し、**発言者と同じ名前・アバターのWebhookを使って、元の文に関係なくメッセージ全体を「うわっ⚡」に書き換えて代理投稿する** Discord Botです。

---

## 🌟 特徴

- **日本語形態素解析による誤爆防止**: 日本語解析エンジン（Janome）を搭載。「ピエロ（えろ）」「チーズ（ちー）」「あくび（あく）」「動かす（かす）」「明日も晴れですしね（しね）」といった、日常会話の単語の一部にNGワードが含まれていても誤検知しません！
- **ローマ字（ヘボン式・訓令式）の自動検知**: 「ガイジ / がいじ」と登録してあれば、伏字目的の `GAIJI` や `GAIZI`、`gaiji`、`gaizi` もすべて自動で同一視して検知します（`BAKA`, `KUSO` なども同様）。
- **漢字・ひらがな・カタカナの自動統一**: 「殺す」と漢字で登録しても「ころす」を検知し、「ばか」と登録しても「バカ」や半角カナ「ﾊﾞｶ」を漏れなく検知します。
- **自然な「書き換え」体験**: Discordの仕様上、Botは他人のメッセージを直接編集できませんが、**Webhook** を利用することで、まるで本人が「うわっ⚡」と言い直したかのように見せることができます。
- **スレッドにも対応**: 通常のチャンネルだけでなく、公開/プライベートスレッド内での発言も置換可能です。
- **簡単なNGワード管理**: メモ帳で `ng_words.txt` を編集するか、Discord内のスラッシュコマンド（`/ng_add` や `/ng_remove`）からリアルタイムに追加・削除できます。

## 🚀 セットアップ手順（5ステップ）

### 1. Discord Developer Portal で Bot を作成する
1. [Discord Developer Portal](https://discord.com/developers/applications) にアクセスしてログインします。
2. 右上の **「New Application」** をクリックし、任意の名前（例: `WordFilterBot`）を入力して作成します。
3. 左メニューの **「Bot」** を開きます。
4. **「Reset Token」** をクリックし、表示されたトークンをコピーしておきます（後で使います）。

### 2. 【重要】Message Content Intent を有効化する
同じく **「Bot」** タブ内の **「Privileged Gateway Intents」** セクションまで下にスクロールします。
- **`MESSAGE CONTENT INTENT`** のスイッチを **ON**（緑色）にし、下部の **「Save Changes」** をクリックします。
> ⚠️ **注意**: これをONにしないと、Botがメッセージの本文を読み取れず、NGワードの検知ができません。

### 3. Bot をサーバーに招待する
1. 左メニューの **「OAuth2」** ➔ **「OAuth2 URL Generator」** を開きます。
2. **SCOPES** で以下にチェックを入れます:
   - `bot`
   - `applications.commands` (スラッシュコマンド用)
3. 画面下部に表示される **BOT PERMISSIONS** で以下にチェックを入れます:
   - `Manage Messages` (メッセージの管理：元メッセージの削除に必須)
   - `Manage Webhooks` (ウェブフックの管理：置き換え投稿に必須)
   - `Send Messages` (メッセージを送信)
   - `Read Message History` (メッセージ履歴の閲覧)
   - `Attach Files` (ファイルを添付：画像添付を引き継ぐ場合)
4. 最下部に生成された **「GENERATED URL」** をコピーしてブラウザで開き、導入したいサーバーを選択して招待します。

### 4. トークンを設定する
このフォルダ内にある [`.env`](file:///c:/Users/omaeh/Downloads/a/.env) ファイルをメモ帳などで開き、Step 1で取得したトークンを貼り付けて保存します。

```env
DISCORD_BOT_TOKEN=ここに取得したBotトークンを貼り付け
```

### 5. Bot を起動する
- **一番簡単な方法**: フォルダ内の [`run.bat`](file:///c:/Users/omaeh/Downloads/a/run.bat) をダブルクリックするだけです。
- または、ターミナル（PowerShell）で以下を実行します:
  ```powershell
  .\.venv\Scripts\python main.py
  ```

コンソールに `ログイン成功: Bot名` と表示されれば準備完了です！

## 📝 サーバーごとのNGワード＆置換文字設定

各Discordサーバーごとに、独自のNGワード追加や検知時の置き換えメッセージ（デフォルト:「うわっ⚡」）をカスタマイズできます。設定はサーバーごとに独立して自動保存されます。

### 方法A: Discordのスラッシュコマンドで操作する（推奨）
（※サーバーで「メッセージの管理」権限を持つユーザーのみ実行可能）

| コマンド | 説明 |
| :--- | :--- |
| `/ng_list` | このサーバーで有効なNGワード一覧、追加したNGワード、現在の置換メッセージ設定を表示します（実行者のみに表示）。 |
| `/ng_add <単語>` | **このサーバー専用**の新しいNGワードを追加します。 |
| `/ng_remove <単語>` | このサーバーからNGワードを削除（除外・無効化）します。 |
| `/ng_message <テキスト>` | **このサーバーで暴言が出た時の置換文字を変更**します（例: `うわっ⚡` ➔ `暴言はダメ！` や `にゃーん🐱` など）。 |
| `/ng_message_reset` | 置換文字を初期設定の「うわっ⚡」に戻します。 |
| `/ng_reload` | `ng_words.txt` およびサーバー設定ファイルを即座に再読み込みします。 |

### 方法B: 全サーバー共通の基本辞書を編集する
[`ng_words.txt`](file:///c:/Users/omaeh/Downloads/暴言チェッカー/ng_words.txt) を直接メモ帳などで開き、1行に1単語ずつ追加・削除してください。
編集後、Discord上で `/ng_reload` コマンドを実行するか、Botを再起動すると全サーバーに反映されます。

## ⚡ 動作例

- **発言**: `お前アホだなｗ`
- **Botの処理**: 元の発言が即座に削除され、
- **置換後**: `うわっ⚡` （または `/ng_message` で設定したお好みのメッセージを、発言者のアイコンと名前で代理投稿）
